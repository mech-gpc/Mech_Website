MECHANICAL WEBSITE: SLIDESHOW AND STUDENT TOOLS

UPLOAD
Extract this ZIP and upload the files and assets folder to your existing GitHub Pages publishing folder. Upload the contents, not the ZIP file. Keep index.html at the website root. Replace matching files. The live site changes only after GitHub deploys your upload.

NOTICE SHEET
Your published Google Sheet is already configured in assets/js/notices-config.js. Name and Link still work exactly as before. To enable dates and filters, add these OPTIONAL headers on row 1 of the SAME published Notices tab:
A: Name
B: Link
C: Date
D: Category
E: Semester

Enter the date as YYYY-MM-DD (for example, 2026-10-17). Notices with dates appear newest first; dates within the past seven days show New. Undated notices remain below dated ones in sheet order. Do not add a date unless it is the correct issue date.
Category: Exam, Academic, Admission, Workshop or General. Custom categories also appear in the filter. Blank category means General.
Semester: 1 to 6. Multiple semesters can be entered as 1,3,5; blank or All means the notice applies to every semester.
Use plain https:// URLs in Link. Visitors must have access to the linked documents.

Keep the Notices tab published as CSV with automatic republishing enabled. Do not replace the tab or change its published link. The website checks for changes every minute while visible; Google publishing cache can add delay. Names and links are public. Search, category and semester filters are on Notice Board. The homepage shows the three newest notices. If the sheet is unreachable, the existing backup notice list appears.

STUDENT QUICK LINKS
Timetables opens Notice Board with a timetable search; Exam Notices opens it filtered to Exam. The calendar, syllabus, manuals and coordinator links use existing department document folders. These filters require the relevant notices to have been entered in your sheet. Virtual Labs opens the existing experiments page.

PHOTOS
Laboratories now includes five facility photos from the existing presentation: three for 3D printing and two for CNC simulator training. Select a photo to enlarge it. Browse with previous/next, arrow keys or swipes. Escape closes the viewer.

SLIDESHOW AND MOBILE
The original 21 presentation slides remain. Playback advances every eight seconds, pauses on hover or focus, and supports slide selection, keyboard arrows, swipes and full screen when supported. Reduced-motion users start paused. Layout and controls adapt to small screens. Original PowerPoint animations/audio are not included in the image slideshow.

VISITOR COUNTER
The displayed visitor count now starts at 1,000 plus the total recorded by GoatCounter. The initial value is set in assets/js/content.js as VISIT_COUNTER_START. Recorded analytics are unchanged. A cached total is shown if the counter service is temporarily unavailable; new devices show the starting count until the total loads.
